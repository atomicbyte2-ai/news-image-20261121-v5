A single 1024×1024 front page that sums up the world news of Saturday 21 November 2026: a giant dated masthead, a one-line summary of the day, a UTC timeline, key numbers, three illustrated lead stories, twelve tiles and 24 briefs pinned on a world map, 39 stories across nine regions. Every story was checked to be dated 21 November, and items from the day before or after are listed in a date-check footer. The image is drawn with Python/PIL by `build_entry.py`; `main.ts` validates the bundled `entry.png` and copies it to the output folder, with no network and identical bytes on every run.

## Run it

```sh
node main.ts
```
